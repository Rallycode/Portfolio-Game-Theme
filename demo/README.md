## Adding the Video to README

Once the video is uploaded to GitHub, you can reference it in the main README.md using one of these methods:

### Option 1: Direct Link (if uploaded to GitHub)
```markdown
![Demo Video](demo/20260210-1622-13.5774142.mp4)
```

### Option 2: GitHub Releases
Upload the video to GitHub Releases and link it:
```markdown
[Watch Demo Video](https://github.com/Rallycode/Portfolio-Game-Theme/releases/download/v1.0/demo.mp4)
```

### Option 3: External Hosting (Recommended for large files)
Upload to YouTube, Vimeo, or similar platform and embed:
```markdown
[![Demo Video](https://img.youtube.com/vi/VIDEO_ID/0.jpg)](https://www.youtube.com/watch?v=VIDEO_ID)
```

### Option 4: GitHub Discussions
Upload to GitHub Discussions and link:
```markdown
[Watch Demo Video](https://github.com/Rallycode/Portfolio-Game-Theme/discussions/1)
```
